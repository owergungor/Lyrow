Lyrow Privacy Policy

Last Updated: November 24, 2026 Publisher: crius Repository: github.com/owergungor/Lyrow

1. Introduction

This Privacy Policy explains how Lyrow handles information when you use the Lyrow desktop application on Windows 10 and Windows 11. Lyrow is designed as a privacy-first, local Windows music companion for synchronized lyrics, ambient edge lighting, and compact media controls.

Lyrow does not require an account, does not collect personal information, and does not include telemetry, analytics, cookies, or advertising SDKs.

2. Information We Collect

Lyrow does not collect personal information or operate any backend servers that store user data. To deliver its features, Lyrow processes limited, non-personal technical data locally on your device and sends minimal search queries to public third-party APIs only when needed:

  • Currently Playing Media Metadata (Local & Ephemeral): Lyrow reads the active track title, artist name, album name, playback duration, playback position, playback status, and album thumbnail locally via the Windows Global System Media Transport Controls (GSMTC) API. When fetching synchronized lyrics or fallback album artwork, only the track title, artist name, and (where applicable) album name and track duration are sent over HTTPS.
  • Real-Time Audio Output Levels (Strictly Local, In-Memory Only): When the optional Edge Light feature is enabled, Lyrow analyzes system audio output locally in real time via Windows WASAPI Loopback to compute frequency spectrum energy for screen-edge lighting. Audio data is processed strictly in RAM and is never recorded, saved to disk, or transmitted over the network.
  • Application Version for Update Checks (Optional): When update checks are enabled or triggered manually, Lyrow queries the public GitHub Releases API and sends a standard HTTP User-Agent header containing the app name and version (e.g., Lyrow/4.4).

3. Information We Do Not Collect

Lyrow does not collect, store, sell, rent, or share:

  • Names, email addresses, phone numbers, or physical addresses
  • User accounts, login credentials, or music service authentication tokens
  • Listening history or user profiles
  • Device identifiers, hardware IDs, MAC addresses, or advertising IDs
  • Location or GPS data
  • Telemetry, usage analytics, or behavioral tracking data
  • Automatic crash reports or diagnostic uploads
  • Browser cookies or cross-app tracking data
  • Audio recordings or microphone input

4. How Information Is Used

The limited non-personal information processed by Lyrow is used solely to provide core application functionality:

  • Synchronized Lyrics: Track title, artist, album, and duration are used to look up synchronized lyrics and display them in time with playback.
  • Album Artwork & Dynamic Visuals: Album thumbnails (and fallback artwork search results when unavailable locally) are used to display cover art and extract color palettes for dynamic backgrounds and Edge Light colors.
  • Audio-Reactive Edge Light: Local, in-memory WASAPI loopback spectrum data drives real-time screen-edge lighting effects.
  • Software Updates: Public GitHub Releases metadata is checked to notify you when a newer version is available. Microsoft Store (MSIX) installations are updated through the Microsoft Store rather than Setup EXE downloads.

5. Third-Party Services

Lyrow connects to the following public third-party services over HTTPS solely to provide its features. Lyrow never sends personal account information or user identifiers to these services. Standard network metadata (such as your IP address and HTTP headers) is handled under each provider's privacy policy:

  • LRCLIB (https://lrclib.net): Used to search and retrieve synchronized and plain lyrics (/api/get and /api/search). Only normalized track name, artist name, optional album name, optional duration, and a standard User-Agent header are sent.
  • Apple iTunes Search API (https://itunes.apple.com): Used as a fallback to retrieve high-resolution album artwork (/search) when local media session artwork is unavailable or low resolution. Only the track artist, title query, and a standard User-Agent header are sent.
  • GitHub Releases (https://api.github.com / https://github.com/owergungor/Lyrow): Used to check for new Lyrow versions and, if you explicitly choose to install an update in the non-Store Setup edition, to download the verified installer. Automatic update checks can be disabled anytime in Settings > Updates.
  • External Web Links (User-Initiated Only): If you click a release notes link or choose to open Apple Music Web (https://music.apple.com/), Lyrow opens the URL in your default web browser.

6. Local Data Storage

All preferences, caches, and logs created by Lyrow remain strictly on your local Windows device and are never uploaded:

  • Application Preferences: Stored locally in %APPDATA%\Lyrow\settings.json (or settings.json next to the executable in Portable mode). Includes theme, language, opacity, Edge Light settings, hotkeys, and update preferences.
  • Lyrics Cache: Retrieved lyrics are cached locally in %APPDATA%\Lyrow\LyricsCache\ as JSON files to improve performance and reduce repeated network requests.
  • Local Diagnostic Logs: Zero-telemetry diagnostic logs are written locally to %APPDATA%\Lyrow\logs\ (or logs\ in Portable mode) solely for local troubleshooting and are never transmitted automatically.
  • Temporary Update Downloads (Setup Edition Only): Downloaded update installers are stored temporarily in %TEMP%\Lyrow\Updates\ and verified before execution.
  • In-Memory Caches: Decoded artwork images and extracted color palettes are stored temporarily in RAM and cleared when Lyrow exits.

You can reset your preferences at any time via Settings > About > Reset to Defaults, or remove all local data by deleting %APPDATA%\Lyrow.

7. Data Security

  • All outbound network requests (LRCLIB, Apple iTunes Search API, and GitHub Releases) use encrypted HTTPS connections.
  • Downloaded Setup update packages are verified for Windows executable integrity and SHA-256 checksum before installation; corrupted or unverified packages are rejected and deleted.
  • Because Lyrow does not collect personal data or operate user databases, there is no centralized server storing your personal information.

8. Children's Privacy

Lyrow does not knowingly collect any personal information from anyone, including children under the age of 13 (or the applicable age of digital consent in your jurisdiction). Because the application requires no account and collects no personal data, no personal information from children is gathered or stored.
