# Lyrow v4.7 — Immersive Music Welcome Experience (V3)

Lyrow v4.7 combines a cinematic, single-screen **Immersive Music Experience** hero showcase with instant, zero-friction preference controls directly on the Welcome screen.

## What's New in v4.7

### Immersive Hero Showcase + Compact Fluent Preferences
- **Cinematic Live Preview Hero:** Glowing 4-edge Edge Light aura framing a frosted-glass miniature Lyrow player with animated 5-band audio spectrum bars, dynamic atmospheric lighting, and a highlighted real-time active lyric line that adapts live to your chosen language.
- **Instant Live Preferences (No Multi-Step Wizard):** A single compact Windows 11 Fluent bar below the headline provides:
  - **Language / Dil:** `Türkçe` / `English` (switches all Welcome copy and preview lyrics instantly).
  - **Theme / Tema:** `System` / `Dark` / `Light` (*Sistem* / *Koyu* / *Açık*) with immediate live window preview.
  - **Music Experience / Müzik Deneyimi:** `Edge Light` (*Kenar Işığı*) and `Dynamic Background` (*Dinamik Arka Plan*) toggles with safe fallback when no audio endpoint is present.
- **One Dominant Primary Action:** High-contrast brand-gradient **Start Listening** (*Dinlemeye Başla*) pill CTA plus a quiet **Customize later** (*Daha sonra özelleştir*) option that applies defaults without forcing any choice.
- **Zero Scroll, Full Protection:** `880×612` DIP (`Scrollable=False`, `Overflows=0`), `Enter` / `Esc` shortcuts, manual reopen from Settings with current preferences preselected, and full v4.5/v4.6 upgrade preservation.
